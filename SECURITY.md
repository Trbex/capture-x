# Reporting a security issue

Use GitHub’s [private vulnerability reporting form](https://github.com/Trbex/capture-x/security/advisories/new) to contact the maintainer. Keep sensitive details in the private report.

Include the REAL Capture X version, Windows build, affected feature and the impact you observed. A minimal example using synthetic content helps the maintainer investigate. Omit personal screen captures, credentials and recordings of other people.

Check the [release notes](https://github.com/Trbex/capture-x/releases) for published fixes. Use the [bug report form](https://github.com/Trbex/capture-x/issues/new?template=bug.yml) for ordinary crashes and layout problems.
