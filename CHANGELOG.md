# Changelog

## 0.2.1 · 26 November 2026

- Fixed a crash when switching appearance modes while a floating window was open. The custom glass backdrop now handles WinUI configuration changes itself.
- Restored enough height in the recording setup panel to show the full **Start recording** button.
- Updated the Windows application icon and added an English product guide with demos from the running application.

[Changes since 0.2.0](https://github.com/Trbex/capture-x/compare/v0.2.0...v0.2.1)

## 0.2.0 · 26 November 2026

- Introduced the graphite toolbar, floating glass menus and Quick Access card. Appearance settings include System, Light and Dark themes, translucency and reduced motion.
- Expanded Annotate with selection handles, editable marks, inline text, blur and redaction. Added recording controls, Studio trimming and thumbnail history to the redesigned interface.
- Published the first portable Windows x64 release through GitHub Actions, with bundled runtimes, OCR data and a SHA-256 checksum.

[0.2.0 release](https://github.com/Trbex/capture-x/releases/tag/v0.2.0)
